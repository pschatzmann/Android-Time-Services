# NTP & CTS Time Services (Android, Kotlin / Jetpack Compose)

This is the Android project. See the [main README](../README.md) and the [documentation](https://github.com/pschatzmann/Android-Time-Services/wiki/Home); tool downloads are in [SETUP.md](SETUP.md).

Quick start (phone connected over USB with USB debugging on):

    export ANDROID_HOME=~/Android/Sdk
    ./gradlew installDebug

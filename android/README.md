# NTP & CTS Time Services (Android, Kotlin / Jetpack Compose)

This is the Android project. Features, limits, permissions, the project layout and the build steps are described in the [main README](../README.md); tool downloads are in [SETUP.md](SETUP.md).

Quick start (phone connected over USB with USB debugging on):

    export ANDROID_HOME=~/Android/Sdk
    ./gradlew installDebug
